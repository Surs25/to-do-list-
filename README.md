# To-Do List Application

A simple To-Do List application built using Python to help users manage and organize their tasks.

## Features
- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Simple and user-friendly interface

## Technologies Used
- Python

## How to Run

```bash
python todo_list.py
```

1. Add Task
